Machine Learning in Production

July 7, 2025 • 12 min read • Copy URL • Share: Twitter LinkedIn
Image: Mountains landscape | Photo by Ales Krivec on Unsplash

Deploying machine learning models in production environments presents unique challenges that extend beyond the traditional software development lifecycle. In this post, I'll share practical insights from my experience taking ML models from experimentation to reliable production systems, focusing on best practices and common pitfalls1.

The ML Production Gap

There's a significant gap between developing a machine learning model in a Jupyter notebook and deploying it as a production system that can reliably serve predictions at scale. This gap involves challenges in data pipelines, model serving, monitoring, and governance.

Many data scientists focus on model accuracy during development but underestimate the operational aspects of keeping models running efficiently in production. The reality is that ML engineering requires a different mindset than ML research or development.

Building Reliable Data Pipelines

Production ML systems depend on reliable data pipelines. Your model is only as good as the data it receives, and in production environments, data quality issues become immediately apparent and impactful.

Here's a simple example of a data validation check you might implement in your pipeline: 

import pandas as pd
import numpy as np
from great_expectations.dataset import PandasDataset

def validate_input_data(df):
    # Convert to GE dataset
    ge_df = PandasDataset(df)
    
    # Define expectations
    ge_df.expect_column_values_to_not_be_null("user_id")
    ge_df.expect_column_values_to_be_between("age", min_value=0, max_value=120)
    ge_df.expect_column_values_to_be_in_set("country", ["US", "CA", "UK", "AU"])
    
    # Get validation results
    results = ge_df.validate()
    return results["success"], results

You can learn more about data validation practices in the Great Expectations documentation .

Model Serving Strategies

How you serve your model can significantly impact performance, cost, and maintenance requirements. Here are the main approaches to consider:

  • Real-time prediction APIs: Low-latency REST or gRPC endpoints for immediate predictions
  • Batch prediction: Processing large volumes of data at scheduled intervals
  • Edge deployment: Running models directly on edge devices for offline capabilities
  • Hybrid approaches: Combining methods based on use case requirements

The API endpoint configuration might look something like: https://api.example.com/v1/predict

Monitoring and Observability

Unlike traditional software, ML systems can silently degrade as data patterns change over time. Comprehensive monitoring is essential for detecting performance issues before they affect users2.

Key metrics to monitor include:

  • Model performance metrics (accuracy, F1, etc.) on validation data
  • Prediction distribution shifts
  • Feature distribution shifts
  • System metrics (latency, throughput, resource utilization)
  • Business impact metrics tied to model outcomes

Conclusion

Successfully deploying machine learning in production requires bridging the gap between data science and software engineering practices. By focusing on robust data pipelines, appropriate serving strategies, comprehensive monitoring, and gradual deployment, you can build ML systems that deliver reliable value in production. Remember that the real work often begins after the model is deployed, as maintaining and improving ML systems is an ongoing process.

// Example monitoring setup for ML model in production
class MLModelMonitor {
  constructor(modelName, metrics = ['accuracy', 'latency', 'drift']) {
    this.modelName = modelName;
    this.metrics = metrics;
    this.alertThresholds = {
      accuracy: 0.05,  // Alert if accuracy drops by 5%
      latency: 100,    // Alert if latency increases by 100ms
      drift: 0.1       // Alert if distribution drift > 0.1
    };
  }

  async checkHealth() {
    const currentMetrics = await this.gatherMetrics();
    const baselineMetrics = await this.getBaseline();
    
    return this.metrics.map(metric => {
      const delta = Math.abs(currentMetrics[metric] - baselineMetrics[metric]);
      const status = delta > this.alertThresholds[metric] ? 'alert' : 'healthy';
      
      return {
        metric,
        status,
        current: currentMetrics[metric],
        baseline: baselineMetrics[metric],
        delta
      };
    });
  }
}
